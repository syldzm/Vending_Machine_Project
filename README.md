# Vending_Machine_Project
# Python Vending Machine

이 프로그램은 Python을 활용하여 제작한 자판기 시뮬레이션 프로그램입니다.

사용자는 상품을 선택하고 금액을 투입하여 상품을 구매할 수 있으며, 관리자는 상품의 재고와 가격, 판매 내역 등을 관리할 수 있습니다.

## 1. 프로젝트 개요

- **개발 언어:** Python
- **프로젝트 유형:** 프로그래밍 프로젝트 과제
- **주요 기술:** Python, 객체지향 프로그래밍, JSON 데이터 관리, GUI
- **개발 목적:** 실제 자판기의 동작 과정을 프로그램으로 구현하고, 데이터 관리 및 사용자 인터페이스 개발 경험 습득 및 과제 제출

## 2. 주요 기능

### 사용자 모드
- 상품 목록 및 가격 확인
- 금액 투입 (1,000원, 500원, 100원, 50원)
- 상품 선택 및 구매
- 잔액 및 거스름돈 처리
- 재고 부족 및 잔액 부족 상황 처리
- 안내문 및 연락처 확인

### 관리자 모드
- 비밀번호를 통한 관리자 접근
- 상품 재고 관리
- 상품 가격 변경
- 판매 내역 확인
- 자판기 잔돈 관리

## 3. 프로젝트 구조

```text
Python-Vending-Machine/
├── main.py
├── gui.py
├── models.py
└── vending_machine_data.json
```

| 파일 | 설명 |
|---|---|
| `main.py` | 프로그램 실행 및 전체 동작 관리 |
| `gui.py` | 그래픽 사용자 인터페이스 |
| `models.py` | 자판기 핵심 기능 및 데이터 처리 |
| `vending_machine_data.json` | 상품 정보 및 프로그램 데이터 저장 |

## 4. 실행 방법

**1. Python 설치**

Python 3 환경이 필요합니다.

**2. 프로젝트 다운로드**

```bash
git clone https://github.com/syldzm/Python-Vending-Machine.git
cd Python-Vending-Machine
```

**3. 프로그램 실행**

```bash
python main.py
```
